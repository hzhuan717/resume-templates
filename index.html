简历模板库

打开模板 → 点文字直接改 → 自动保存在你的浏览器 → 一键导出 PDF。无需注册，数据完全在你本机。

免费使用免注册数据不上传支持证件照替换支持 JSON 备份迁移
怎么用
  1. 挑一个模板点进去；
  2. 点纸张里的文字直接改，改动自动保存在本机浏览器；
  3. 工具条「打印 / 导出PDF」生成简历（打印机选"另存为 PDF"、边距选"无"）。
照片与换设备
  1. 工具条「替换照片」上传证件照（带"可换照片"标的模板支持）；
  2. 换电脑/换浏览器：用「备份JSON」导出，在新设备「导入JSON」。
隐私说明
本站是纯静态网页，没有任何服务器。你的简历内容只保存在你自己浏览器的 localStorage 里，清除浏览器数据会删除简历，请先备份。
没有匹配的模板，换个关键词试试。
建议使用 Edge / Chrome 浏览器获得最佳体验。本站模板仅供个人求职使用。
提示：每个模板保存各自的内容；想同时维护多份简历，可在不同模板中各存一份，或用「备份JSON」区分存档。
