为什么这里不用注册

简历里有姓名、电话、住址。我们没有服务器，也不想要你的账号——内容只存在你当前浏览器的 localStorage 里，关掉网页也在，清浏览器数据才会没。

  • 1不上传：没有后端接口，模板和内容都在本机加载。
  • 2不登录：省掉手机号、验证码和“升级会员”的打断。
  • 3可带走：导出 HTML 或 JSON，换电脑、换浏览器都能继续改。
  • 4可离线：模板是静态文件，断网也能打开已下载的页面。
localStorage {
  "qmt:html:t001": "<div class=page>…",
  "qmt:photo:t001": "data:image/jpeg;base64,…",
  "qmt:theme:t001": "#264A5A"
}
// 只在这台设备、这个浏览器里

常见问题

导出、保存、换设备，都在这里。

怎么导出 PDF？打印出来是 A4 吗？

打开模板后点工具条「打印 / 导出PDF」，在打印对话框里选择“另存为 PDF”，纸张 A4，边距选“默认”。系统已内置 A4 页边距；如果内容较多，工具条会提示页数，建议先精简到 1 页。

内容保存在哪里？会丢吗？

保存在你当前浏览器的 localStorage 里，不上传。清理浏览器数据、换浏览器或无痕窗口会看不到之前的内容；重要简历请用「备份JSON」导出保存。

换电脑 / 换浏览器怎么继续改？

在原设备点「备份JSON」下载文件，在新设备打开同一个模板，点「导入JSON」选择该文件即可恢复。也可以直接下载 HTML 带走。

为什么每个模板是分开保存的？

当前版本以模板为单位保存，方便你对比不同版式。想同时维护多份简历，可以复制 JSON 备份区分存档；后续会加入“我的简历”统一管理。

可以换照片、换颜色和字体吗？

带“可换照片”标记的模板支持上传证件照；工具条「外观」可换强调色和正文字体。不同模板的可换范围略有差异，以工具条实际显示为准。
